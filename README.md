🚕 Predictive Driver Positioning
<sub><b>Research</b> · Team project · 📄 Published at IEEE ETCC 2026</sub>

A two-stage, welfare-aware system that tells gig drivers where to wait across 263 NYC TLC zones. XGBoost forecasts demand in 15-minute windows, then a tuned weighted-sum model scores each zone on revenue, idle time, saturation and fuel cost.
